## 交互注意事项

- 从地域级目录切换到具体可用区时，前端会清除原先选择的机型，需要在该可用区目录中重新选择。这是库存有效性保护逻辑。
- 未选择可用区时无法选择子网，因此无法形成可询价的完整购买规格。
- 启用真实购买后，还需要通过页面的操作员访问入口提交 Operator token。
- 实际下单前服务端会再次校验报价、库存、金额上限和购买门禁；报价或库存变化仍可能使订单被拒绝。
- 受限测试进程首次实时读取镜像时出现 Windows 套接字权限错误并回退完整缓存；将 API 切换到允许访问云厂商接口的进程后，实时询价成功。缓存回退不是本次购买阻塞项。
